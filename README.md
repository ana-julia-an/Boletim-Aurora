# 📚 Boletim Aurora

Um sistema de gerenciamento de boletins escolares desenvolvido em Python como projeto acadêmico para a disciplina de **Programação de Computadores**.

## 🎯 Sobre o projeto

O Boletim Aurora é uma aplicação executada no terminal que permite cadastrar informações de alunos, registrar notas e faltas por disciplina e gerar um relatório com as médias finais e a situação escolar.

O projeto foi desenvolvido com o objetivo de aplicar conceitos fundamentais de lógica de programação e desenvolvimento em Python.

## ⚙️ Funcionalidades

- Cadastro do nome do aluno e da escola.
- Registro de diferentes disciplinas.
- Cadastro de quatro notas por disciplina.
- Cálculo automático da média final.
- Registro e validação do número de faltas.
- Verificação da situação escolar: aprovado ou reprovado.
- Geração de relatório final com os dados cadastrados.
- Validação de entradas e tratamento de erros.

## 🛠️ Tecnologias utilizadas

- **Python 3:** linguagem utilizada no desenvolvimento.
- **Funções:** organização e reutilização do código.
- **Listas e dicionários:** armazenamento dos dados.
- **Estruturas condicionais e de repetição:** controle do fluxo do programa.
- **Tratamento de exceções:** validação das entradas do usuário.

## ▶️ Como executar

1. Faça o download ou clone este repositório.
2. Certifique-se de ter o Python 3 instalado.
3. Abra a pasta do projeto no terminal.
4. Execute o arquivo Python principal:

```bash
python codigo_boletim/boletim.py
```

## 📋 Funcionamento

Ao iniciar o programa, o usuário informa o nome do aluno e da escola. Em seguida, cadastra as disciplinas, as quatro notas de cada uma e o número de faltas.

Após finalizar os cadastros, o sistema calcula as médias e apresenta um relatório com a situação escolar de cada disciplina.

**Critério de aprovação implementado:** média igual ou superior a 6,0 e até 25 faltas.

## 🎓 Objetivo acadêmico

Este projeto foi desenvolvido para colocar em prática conhecimentos de lógica de programação, funções, estruturas de dados, condicionais, laços de repetição e tratamento de exceções.
